# Overview
Aburamushi is an app I made becaause I wanted to learn Japanese. It's a tool I've been working on for the past few days, and I figured that it is now in a shareable state.

I struggled with learning through [Anki](https://apps.ankiweb.net/), I yearned for a tool that would allow me to learn via immersion.

To my dismay, I could find no such tool. Or well, I *did* find such a tool in the form of [Yomitan](https://yomitan.wiki/) and [Mokuro](https://github.com/kha-white/mokuro), though they weren't as seamless or consistent as I had wanted. 

So, introducing my take on the subject:

# Aburamushi
Get it? It's Japanese for Aphid. Yeah, yeah... Lazy I know. I also don't care.

Anyways, what makes this app different from the others is a few things:

1: The app uses a specific format called an ABMS file. It's basically a fancy zip file, but it contains a lot of information about the specific manga you are reading, this enables a few things that can't be done with other readers.

2: It uses it's own, custom-built version of Yomitan. It accepts dictionaries in the Yomitan format, so your favorites still work, don't worry. This mean no extra extensions or downloads are needed (besides the dictionaries of course)

3: Because it is a standalone app, we can do a bunch of other fun stuff! It doubles as a reader, so...
 - The app includes complex trackers of your progress
 - The app features custom AI-powered quizzing tools (Japanese is a nuanced language. I don't believe in stuff like Duolingo as they're too restrictive. There are multiple "correct" translations of sentences and everything is context based. Because of this, I don't believe you can actually "judge" translations unless you use an external translator, such as a genuine interpreter, or, the more realistic choice: An LLM.)
 - A built in library for accessing your manga in one click
